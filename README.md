# CRAFT: демо приложения-читалки · v3

Публичный адрес: https://anboxdesign.github.io/craft-reader-demo/

Читалка показывает 44 оригинальные страницы тестового PDF. Установка на главный экран и офлайн-чтение добавлены к существующему интерфейсу. Оплаты, аккаунтов, серверной синхронизации и выдачи персональных копий в демо нет.

## Проверить на телефоне

1. Откройте адрес читалки в браузере отдельной страницей.
2. Нажмите значок телефона / «Приложение» в шапке.
3. На iPhone в Safari: «Поделиться» → «На экран “Домой”» → «Добавить». На Android используйте кнопку установки, если браузер её предлагает, либо меню Chrome → «Установить приложение» / «Добавить на главный экран».
4. Откройте CRAFT с главного экрана. В окне «Приложение» нажмите «Сохранить для офлайн-чтения».
5. Дождитесь надписи «Сохранено · все 44 страницы доступны без интернета» и проверьте чтение в авиарежиме.

Полная офлайн-копия занимает около 8 МБ. Данные сохраняются в конкретном браузере/приложении на конкретном устройстве. После очистки данных браузера или удаления копии системой фрагмент потребуется сохранить заново. Место чтения восстанавливается локально; между устройствами не синхронизируется.

## Вставка через VibeBlock

Ранее выданный iframe продолжает работать без замены:

```html
<iframe src="https://anboxdesign.github.io/craft-reader-demo/"
  title="Фрагмент книги «Фиолетовый CRAFT»"
  style="display:block;width:100%;height:100vh;height:100dvh;border:0;"
  allow="fullscreen" allowfullscreen></iframe>
```

Во встроенной читалке окно «Приложение» предлагает открыть прямой адрес. Устанавливайте и сохраняйте офлайн-копию именно там, чтобы не зависеть от ограничений хранилища стороннего iframe.

## Публикация и обновление

Статический сайт без сервера: HTML, CSS, JS, PDF и локальный PDF.js 5.4.624 (лицензии в `vendor/pdfjs`). Исходный PDF сохранён без изменения. Сборки v1/v2 являются сохранёнными базовыми версиями.

Список офлайн-файлов и версия кэша генерируются скриптом основного проекта:

```powershell
node scripts/build-craft-reader-pwa.cjs exports/github-pages-reader-v3
```

Перегенерируйте список после изменения публикуемых файлов. Для следующего релиза создайте новую версию пакета. Service worker ограничен каталогом читалки и удаляет только собственные устаревшие кэши. Новый worker активируется после закрытия окон прежней версии. После обновления проверьте статус сохранения фрагмента.

## Позднее: Timeweb

Эту папку можно перенести целиком на HTTPS-хостинг с корректными MIME-типами (`.mjs` — JavaScript, `.wasm` — application/wasm, `.webmanifest` — application/manifest+json). Пути, manifest и service worker относительные, подходят для корня и подкаталога. Поведение чтения не зависит от GitHub.

Для продажи полной книги потребуется отдельная серверная часть: подтверждение оплаты, заказы и права доступа, вход/восстановление доступа, закрытое хранение, персонализация книги и синхронизация. Текущий публичный PDF не является защищённой выдачей после оплаты. Старый backend под Yandex Cloud нельзя включить для PDF простой сменой адреса: его обработчик персонализирует EPUB и должен быть адаптирован под выбранный формат и Timeweb.

**Главное требование защиты:** каждый купленный файл прошивается ID покупателя и номером заказа на страницах и в метаданных; email связан с ID на сервере. Метка встраивается в PDF/EPUB, а не только отображается интерфейсом. При ошибке маркировки файл не выдаётся. Критерии серверной реализации и проверки перечислены в `PROTECTION.md`; в демо этот backend ещё не реализован.

При переходе с github.io на другой домен локальный прогресс, установка и кэш автоматически не переносятся: пользователю понадобится открыть новый адрес, установить приложение и сохранить книгу снова. Для сохранения адреса в дальнейшем используйте постоянный собственный домен.
