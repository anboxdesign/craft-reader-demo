# CRAFT: демо приложения-читалки · v7

[Открыть демо](https://anboxdesign.github.io/craft-reader-demo/).

В демо используется присланный 24 сентября файл «CRAFT .pdf»: 5 разворотов, которые читалка показывает как 10 страниц фрагмента. На телефоне видна одна половина разворота; на компьютере — обе. Скачиваемый PDF сохранён побайтово, без пересборки и сжатия: 18 487 898 байт (18,5 МБ). Поддерживает установку на главный экран и сохранение фрагмента для чтения без интернета. Оплаты, аккаунтов и выдачи персональных копий в демо нет.

## Установка на iPhone

1. Нажмите «Книга на главном экране» над книгой или значок телефона / «Приложение» в шапке. Откроется комикс из трёх шагов.
2. Если ссылка открыта в Telegram, нажмите «Открыть в Safari». Если система спросит разрешение на переход, подтвердите его.
3. Если переход не сработал, раскройте «Всё ещё в Telegram?» и скопируйте ссылку. Откройте Safari самостоятельно и вставьте ссылку в адресную строку. При запрете автоматического копирования появится поле для ручного выделения.
4. В Safari: «Поделиться» → «На экран „Домой“» → «Добавить». Если доступен переключатель «Открыть как веб-приложение», включите его. Если действие скрыто, проверьте «Редактировать действия» в меню «Поделиться».
5. Откройте CRAFT с главного экрана. В окне «Приложение» нажмите «Сохранить для офлайн-чтения» и дождитесь статуса «Сохранено». Проверьте чтение в авиарежиме.

Подсказка не прерывает обычный вход: её можно скрыть крестиком и открыть снова через окно «Приложение». При переходе по подготовленной ссылке `?install=2` автоматически открывается второй шаг — меню Safari. Прохождение инструкции не считается подтверждением установки. К офлайн-настройкам можно перейти из любого шага.

Инструкция Safari: [руководство Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios). Показанная в демо подсказка доступна на iPhone/iPad независимо от распознавания Telegram: по строке браузера надёжно отличить все варианты встроенного браузера нельзя. В установленном приложении лишняя инструкция скрыта.

## Android и офлайн-чтение

В Chrome используйте кнопку «Установить приложение», если браузер её предлагает, либо соответствующий пункт меню браузера. После установки откройте CRAFT и сохраните фрагмент из окна «Приложение».

Полная офлайн-копия занимает около 32 МБ. Хранится локально в конкретном браузере/приложении; прогресс между устройствами не синхронизируется. При удалении данных браузера или очистке хранилища системой потребуется сохранить книгу снова.

## Tilda / VibeBlock

Существующий iframe продолжает работать:

```html
<iframe src="https://anboxdesign.github.io/craft-reader-demo/"
  title="Фрагмент книги «Фиолетовый CRAFT»"
  style="display:block;width:100%;height:100vh;height:100dvh;border:0;"
  allow="fullscreen" allowfullscreen></iframe>
```

На iPhone окно «Приложение» предлагает открыть прямой адрес самой читалки в Safari. Используется схема `x-safari-https:`, которую применяет [сам Telegram](https://github.com/TelegramMessenger/Telegram-iOS/blob/master/submodules/OpenInExternalAppUI/Sources/OpenInOptions.swift#L94-L100). Это попытка перехода по явному нажатию: работа зависит от версии iOS и браузера, результат не выдаётся за успешный автоматически. На локальном HTTP-адресе вместо такой ссылки показывается ручной путь. На других устройствах остаётся переход «Открыть читалку отдельно».

## Сборка и обновление

Статический сайт: HTML, CSS, JS, исходный PDF и 10 изображений WebP без потерь для отображения страниц. PDF.js в этой версии не используется. Базовые версии v1–v6 сохранены без изменений. Для следующего релиза создайте новый пакет.

Команда из корня основного проекта:

```powershell
node scripts/build-craft-reader-pwa-v7.cjs exports/github-pages-reader-v7
```

В исходном PDF страницы состоят из растровых изображений; выделяемого текста и активных ссылок в нём нет. Изображения подготовлены из PDF в исходном разрешении: 1866 × 2953 px на страницу. Декодированные RGB-пиксели каждого WebP совпадают с соответствующей половиной рендера Poppler. Нумерация читалки 1–10 относится к фрагменту; печатные номера внутри книги сохранены. Оглавление соответствует этому фрагменту.

Сборщик создаёт иконки, список ресурсов, версию кэша и списки побайтово неизменённых файлов относительно сохранённых v3/v4/v5/v6. Для этой команды требуются все четыре папки. Service worker переносит в новый кэш только побайтово неизменённые ресурсы. Старый PDF не переносится вместо нового. Новый фрагмент нужно сохранить кнопкой заново, даже если прежняя книга уже была сохранена. Позиция новой книги отделена от старой и при первом открытии начинается с первой страницы.

Чтобы получить обновление, откройте читалку с интернетом, затем закройте все её вкладки/окна и откройте снова. Новый worker ждёт закрытия старой версии; обновление не прерывает текущее чтение. После обновления статус в окне «Приложение» показывает фактическую готовность офлайн-копии.

## Timeweb и защита купленных книг

Папка переносится целиком на HTTPS-хостинг с корректными MIME-типами: `.mjs` — JavaScript, `.wasm` — application/wasm, `.webmanifest` — application/manifest+json. Пути относительные. Смена домена требует повторной установки и сохранения книги; локальный прогресс автоматически не переносится.

Для продаж нужна серверная часть: подтверждение оплаты, права доступа, закрытое хранение и выдача персональной копии. **Каждая купленная книга должна содержать ID покупателя и номер заказа на страницах и в метаданных самого файла**, email связан с ID на сервере. При ошибке маркировки файл не выдаётся. Требования: `PROTECTION.md`. Текущий публичный фрагмент этой защитой не оснащён.

Подробные результаты и границы проверки: `QA.md`.
