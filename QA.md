# Проверка CRAFT PWA · v5

23 сентября 2026. Изменения: основная кнопка «Открыть в Safari»; копирование под раскрываемым пунктом «Safari не открылся?»; сохранение книги при обновлении из v3/v4.

## Новая проверка короткого пути

В Chrome и WebKit проверены HTTPS-ссылка на прямой адрес читалки, отсутствие автоматического перехода, явное нажатие, доступность запасного пути при отмене, iframe другого origin, закрытие/возврат фокуса, увеличение текста до 200%. Короткая инструкция проверена отдельно и в собранной читалке на 320, 360, 375, 390, 412, 599, 699, 700, 768, 899, 900, 1440, 3840 px и 844 × 390. Системный запуск Safari перехвачен тестом и не считался проверенным. HTTPS-фикстура предназначена для интерфейса, её service worker отключён; сохранение проверено отдельно с настоящим worker.

Сценарий: `tests/verify-craft-reader-safari-handoff.cjs`. Результаты: `artifacts/reader-pwa-v5/safari-handoff-qa.json`.

## Результаты

- 20 проверок установки и обновления: iPhone с Safari-подобным UA и UA без Safari, iPad с desktop UA, установленное приложение, Android; успешное копирование, отказ и отсутствие Clipboard API; настоящий iframe с другим origin без разрешения на буфер обмена.
- Копируется адрес самой читалки, без query/hash и без подмены адресом родительской страницы Tilda. При отказе показывается выделенное поле только для чтения; ложного сообщения об успехе нет.
- Новая подсказка проверена отдельно и в собранной читалке на 320, 360, 390, 599, 699, 700, 768, 899, 900, 1440, 3840 px; горизонтальный экран 844 × 390. Проверены увеличение текста до 200%, прокрутка, видимая кнопка закрытия, возврат фокуса. Найденное переполнение при крупном тексте устранено.
- 16 общих проверок PWA: окно приложения, полный комплект офлайн-ресурсов, ошибка HTTP 503 и повторное сохранение, все 44 страницы без сети, перезагрузка, повторное открытие, сохранение позиции и изоляция чужих кэшей.
- 18 проверок чтения, Chrome после полного перезапуска и WebKit при обрыве HTTP-транспорта ранее пройдены на v4; код PDF-читалки не изменён. На v5 повторены 16 проверок PWA, включая все 44 страницы без сети.
- Обновления настоящих сохранённых v3 и v4 на том же адресе до v5 проверены отдельно: новая оболочка активируется после закрытия старых страниц, сохранённый фрагмент остаётся готов к офлайн-чтению, позиция 21 восстанавливается без сети. В новый кэш переходят только файлы, для которых сборщик подтвердил побайтовое совпадение с соответствующей базовой версией.

Сценарии основного проекта для v5: `tests/verify-craft-reader-ios-install.cjs`, `tests/verify-craft-reader-pwa.cjs`. Результаты и скриншоты: `artifacts/reader-pwa-v5/`, включая отдельные папки `from-v3/` и `from-v4/`.

## Проверки на телефонах

Пользователь ранее подтвердил установку на Android. В присланных скриншотах тестировщик сообщает об успешном пути через Safari на iPhone и отсутствии пункта добавления на главный экран в показанном меню Telegram. Эти сообщения относятся к предыдущей версии.

Новый сценарий v5 в системном интерфейсе Telegram/Safari на физическом iPhone из этого окружения не проверен. Эмуляция UA, WebKit для Windows и размеры экрана не заменяют такую проверку. Кнопка использует `x-safari-https:` по примеру [исходного кода Telegram](https://github.com/TelegramMessenger/Telegram-iOS/blob/master/submodules/OpenInExternalAppUI/Sources/OpenInOptions.swift#L94-L100). Доступность перехода зависит от системы и приложения; копирование остаётся запасным путём. Нет автоматического запуска при загрузке, таймеров переадресации или ложного сообщения об успехе.

Демо содержит публичный фрагмент; серверная персонализация покупки здесь ещё не реализована. Требование встроенного ID покупателя/заказа зафиксировано в `PROTECTION.md`.
