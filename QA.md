# Проверка CRAFT PWA · v4

23 сентября 2026. Изменения: инструкция перехода из Telegram в Safari, копирование прямой ссылки и ручной запасной путь, сохранение ранее загруженной книги при обновлении v3 → v4.

## Результаты

- 20 проверок установки и обновления: iPhone с Safari-подобным UA и UA без Safari, iPad с desktop UA, установленное приложение, Android; успешное копирование, отказ и отсутствие Clipboard API; настоящий iframe с другим origin без разрешения на буфер обмена.
- Копируется адрес самой читалки, без query/hash и без подмены адресом родительской страницы Tilda. При отказе показывается выделенное поле только для чтения; ложного сообщения об успехе нет.
- Новая подсказка проверена отдельно и в собранной читалке на 320, 360, 390, 599, 699, 700, 768, 899, 900, 1440, 3840 px; горизонтальный экран 844 × 390. Проверены увеличение текста до 200%, прокрутка, видимая кнопка закрытия, возврат фокуса. Найденное переполнение при крупном тексте устранено.
- 16 общих проверок PWA: окно приложения, полный комплект офлайн-ресурсов, ошибка HTTP 503 и повторное сохранение, все 44 страницы без сети, перезагрузка, повторное открытие, сохранение позиции и изоляция чужих кэшей.
- 18 проверок чтения: промежуточные размеры и 3840 × 2160, листание, свайпы, масштаб, содержание, история, восстановление, отсутствие JavaScript, ошибки PDF/worker, reduced motion и все страницы PDF.
- Chrome: проверка installability без ошибок; полный перезапуск браузера с сохранённым профилем и отключённой сетью/HTTP-кэшем сохраняет страницу 21.
- WebKit для Windows: офлайн-сохранение, перезагрузка, листание и поворот при обрыве HTTP-транспорта; новая подсказка и ручное копирование при отсутствующем Clipboard API.
- Обновление настоящей сохранённой v3 на том же адресе до v4: новая оболочка активируется после закрытия старых страниц, сохранённый фрагмент остаётся готов к офлайн-чтению, позиция 21 восстанавливается без сети. В новый кэш переходят только файлы, для которых сборщик подтвердил побайтовое совпадение с v3.

Сценарии основного проекта: `tests/verify-craft-reader-ios-install.cjs`, `tests/verify-craft-reader.cjs`, `tests/verify-craft-reader-pwa.cjs`, `tests/verify-craft-reader-pwa-browsers.cjs`. Результаты и скриншоты: `artifacts/reader-pwa-v4/`.

## Проверки на телефонах

Пользователь ранее подтвердил установку на Android. В присланных скриншотах тестировщик сообщает об успешном пути через Safari на iPhone и отсутствии пункта добавления на главный экран в показанном меню Telegram. Эти сообщения относятся к предыдущей версии.

Новый сценарий v4 в системном интерфейсе Telegram/Safari на физическом iPhone из этого окружения не проверен. Эмуляция UA, WebKit для Windows и размеры экрана не заменяют такую проверку. Само приложение не меняет системное меню Telegram и не обещает автоматически открыть Safari.

Демо содержит публичный фрагмент; серверная персонализация покупки здесь ещё не реализована. Требование встроенного ID покупателя/заказа зафиксировано в `PROTECTION.md`.
